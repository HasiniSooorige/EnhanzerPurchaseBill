# Enhanzer Purchase Bill

A full-stack web application developed as part of the Enhanzer Full Stack Developer assignment.

## Technologies

- Backend: ASP.NET Core Web API (.NET 8)
- Frontend: Angular and TypeScript
- Database: Microsoft SQL Server

## Planned Features

- User login using the provided external API
- Saving user locations in SQL Server
- Protected Purchase Bill page
- Item entry, calculations, and purchase summary

## Project Structure

- `EnhanzerPurchaseBill.Api/` — ASP.NET Core Web API
- `frontend/` — Angular application (to be added)
- `database/` — SQL scripts (to be added)
